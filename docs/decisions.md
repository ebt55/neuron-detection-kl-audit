# Technical Decision & Engineering Log

This document records engineering choices, precision bugs caught, data provenance checks, and budget accounting across both parts of the project.

---

## 1. Part 1 (`Qwen/Qwen3-1.7B` Held-Out Detection Audit)

- **Sampling & dataset:** `50` MLP neurons (`100` signed poles) across `L4` (positive control early token detectors, `13` neurons), `L11` (`13`), `L18` (`12`), `L24` (`12`) extracted in verified hook parity (`max |F.silu(g)*u - down_proj_in| = 0.00e+00`) over `2,000,073` tokens of `HuggingFaceFW/fineweb-edu` (`sample-10BT`, ODC-By), partitioned by `doc_id % 2` into `train_label` (`1,007,383` tokens) and `eval` (`992,690` tokens).
- **Pre-heldout labeler bug caught:** Initial `gpt-4.1-mini` labeling produced phrase repetition loops on several poles; replaced with `gpt-4.1` (`$0.4542`, automated loop rejection) before generating or evaluating `heldout_80`.
- **Structural safeguards enforced in `src/w_audit/`:**
  1. Weak-band context cleanliness (`other_max_act_dir < P90`) removing `~95%–97%` of raw weak-band candidate windows that contained unmarked high-activation neighbor tokens.
  2. Exact `69`-token window (`60 + <<target>> + 8`, zero `<bos>` position `0`, zero truncation).
  3. Exact `k/k` Slot-A/B cell balance across every `(pole_id, band, distractor_type)` cell.
  4. Single unified judge prompt template (`"(none provided)"` for `no_label`, zero `"strongly"`), `1` pair per API call (never 10-pair batching).
  5. Explicit exclusion of `"unparseable"` and `"logprob_tie"` outcomes (`0` across all `38,224` calls).
  6. Binary 2AFC detection accuracy + neuron-clustered bootstrap CIs (`B = 1,000`, `seed = 42`).
  7. Strict cross-layer `wrong` donors (`text-embedding-3-small` boilerplate-stripped cosine `<= 0.65`) and strict Tier-0 same-layer `w_gate` neighbor distractors (`nearest_wgate_tier0` with zero fallback tiers).
- **Prediction checks written prior to the held-out run:** All Part 1 predictions were written before running `heldout_80` (`40` neurons / `80` poles) on the same day, not independently timestamped. Three predictions missed: `wrong` `p75-90` accuracy (`0.515 > 0.50`), `p90-97` marginal gate-open lift (`+0.029 < +0.08`, `0.561` vs `0.532`), and `nearest_wgate_tier0` matched difference (`-0.013`, `n = 32`, `0.706` vs `0.719`, vs `<= -0.02`). Everything else (post-hoc ablations, `4B` evaluation, causal correlation analyses) was exploratory.
- **Part 1 spend:** `$14.3695` across `38,224` judge calls + `$0.4542` `gpt-4.1` labels = `$14.8237`. Exploratory follow-ups included unfiltered weak-band leakage (`4,800` calls, `$1.8897`), `examples_as_label` (`1,200` calls, `$2.2184`), and zero-cost `p97-99` (`n=344`, `0.594`) vs `p99-99.9` (`n=136`, `0.679`) split.

## 2. Part 2 (`Qwen/Qwen3-4B` Multi-Band Audit on `Ulto85/neurons-kinda-clean`)

- **Upstream provenance & exclusions:** Imported from [`Ulto85/neurons-kinda-clean`](https://github.com/Ulto85/neurons-kinda-clean) commit `85c71b7c2876a38f2a17ee2c6bf3da1ec16f09c3` (MIT license, verbatim at `data/qwen4b/ulto85/LICENSE`). Ulto85 labels and simulator ratings were generated by Claude models (Opus explainer, Sonnet/Opus simulator). Out of `280` neurons (`560` poles) in `e3_neurons.json`, `278` are scored in `e3_scores.json` (`(12, 1597)` and `(24, 289)` unscored), and `132` weak/negligible poles are excluded (`424` active poles kept: `132` unipolar + `146` bipolar).
- **Disjoint FineWeb text:** Evaluated on `HuggingFaceFW/fineweb` (`sample/10BT/000_00000.parquet`, ODC-By): `1,536,000` tokens from rows `60,000..64,789` (detection & corpus energy) and `8,192` tokens from rows `65,000+` (`fp32` KL), strictly disjoint from Ulto85's training/scoring rows `0..59,999`.
- **Precision bug caught (`bf16` -> `float32` KL):** An initial `60`-neuron `bf16` ablation run suffered a `~4.5e-4` mantissa rounding noise floor (~`100x` larger than true `~1e-6–2e-5` single-neuron mean-ablation KL; additivity ratio `2.71`). Re-running in exact 4-stage IEEE-754 `float32` (`allow_tf32=False`) gave exact `0.00e+00` zero-ablation sanity KL and `1.0000` median 4-band additivity ratio. All full-corpus `n = 278` `4B` band-KL measurements and all `n = 50` `1.7B` band-KL measurements ran in exact `float32`.
- **Post-hoc `top100` sweep & lexical overlap:** Because `295/424` (`69.6%`) active poles had `p99.9 < 0.20 * max_act_dir`, a post-hoc `top100` sweep (`8,480` calls, `$4.5314`) was added after `p99.9+`. `top100` snippets exhibit `30.6%` exact word overlap (`37.9%` case-insensitive substring overlap) with Ulto85 label strings (computed from the `top100` snippet file `snippets_4b_top100.jsonl`, which is not shipped).
- **Judge slot preference:** `gpt-6.1-terra@none` chose Slot B slightly more often than Slot A (`P(pred=A) = 0.454` `p99.9+`, `0.474` `top100`, `0.415` `no_label`); exact `k/k` cell balance neutralizes first-order bias in forced-choice accuracy.
- **Statistical & imputation corrections:**
  - Reported per-pole (`0.828` `p99.9+`, `0.888` `top100`) and per-neuron (`0.839`, `0.897`) means explicitly.
  - Separated genuine neuron-clustered bootstrap CIs (`neuron_cluster_all_4_bands`), naive pair-level CIs (`flattened_neuron_band_pair`), within-band $\rho$, and a 1,000-permutation neuron-shuffled null (`seed=42`) for pooled `EnergyShare` vs. `KLShare` sanity checks.
  - Logged exact probability-floor imputation rates in YES/NO ordinary-text probes (`96.4%` `terra`, `89.2%` `luna`).
  - Documented base rates across `278` neurons (`267/278` `sim_cal_rec < 0.50`, `251/278 < 0.25`) alongside conditional pass rates (`0/43` failing `top100 >= 0.80` reach `sim >= 0.25`; `63/235` passing reach `active >= 0.50` vs `1/43`).
